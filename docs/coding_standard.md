# 代码维护规范

适用 Python 3.11；命名、类型、格式以 pyproject.toml 和统一验收命令为准。

1. 根目录脚本仅作为命令入口；公共实现进入 src，不在运行脚本之间互相导入。
2. 几何计算、文件读写、可视化和流程编排分别维护。优先复用 CSV 读写和 annotate，避免重复实现坐标约定。
3. 公共函数写参数/返回类型；涉及几何的注释解释坐标系、尺度、误差口径。保留必要数学符号，避免为追求短函数拆散完整公式。
4. 图像检测允许 OpenCV 所需 float32；数值优化投影使用 float64，避免有限差分精度不足。
5. 数据错误显式报错或记失败行，不填造观测和位姿。原图只读，避免隐式覆盖。
6. 不因测试结果更改标定选模规则。数值改动需合成真值测试，并比较真实数据指标。
7. 重构保持已有命令和 CSV 约定兼容；更改对外字段时同步更新 data_contracts.md 和回读测试。

本次保留的改进空间：部分流程 main 仍较长，模型和观测字典含 Any；下一次功能扩展可引入数据类或 TypedDict，但不将重构范围扩展到替换已经验证的几何实现。

提交或交付前运行：

```bash
.venv/bin/python check_quality.py --with-results
```

缺少实际数据产物时去掉 --with-results。报告在 outputs/quality/quality_checks.json；已配置 GitHub Actions；本地执行证据和远程 CI 结果需分别查看。
