# 文件访问与写入范围

程序没有登录、用户角色、令牌或数据库行级权限。唯一执行身份是启动程序的本地操作系统用户；应用不提供独立权限隔离。

| 资源 | 读取 | 写入 | 控制方式 |
|---|---|---|---|
| `dataset/` 原图与题目 | 读取 BMP；题目用于说明 | 流程不写原图 | 代码读写路径约定与操作系统权限 |
| 配置与依赖文件 | 启动、安装时读取 | 运行流程不改配置 | 操作者编辑 |
| 输出根目录 | 后续阶段读取 | 创建或覆盖结果、PNG、HTML | 配置或可视化 `--output-dir` 指定 |
| `.venv/` | 执行依赖 | 安装依赖时写入 | 操作系统权限 |
| `outputs/quality/quality_checks.json` | 交付者检查 | 每次质量检查覆盖 | check_quality.py 固定在项目 outputs 下 |

配置可以指定其他可写路径，程序不充当文件系统沙箱。输入和输出路径应由本地可信操作者管理，不将这些脚本直接作为接受外部用户路径的网络接口。

运行时不需要 API 密钥，不上传图像，不发送消息，不调用远程服务。文件不可读或输出不可写应修正权限或配置；不使用提权掩盖路径错误。
